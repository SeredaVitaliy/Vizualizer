# Студия

Локальная программа для дизайнера меню. Все нейросети работают на компьютере, бесплатно и без подписок.

## Что умеет
- **Улучшить**: резкость, очистка от шума и артефактов JPEG, увеличение в 2–4 раза (Real-ESRGAN).
- **Фон и лишнее**: вырезать объект с фона (BiRefNet), убрать предмет, надпись или пятно кистью (LaMa).
- **Правка словами**: «тёплый свет», «добавь пар», «деревянный стол» — для всей картинки или выделенной области (FLUX.2 klein 4B).
- **Создать**: картинка по описанию с готовыми стилями для меню.
- **Проверка макета**: PDF или картинка. Мгновенно проверяет единообразие граммов, валюты и цен, кавычки, пробелы, смешанную раскладку. С ИИ дополнительно ищет опечатки и разбирает дизайн страницы (Qwen3-VL).
- **Ассистент**: тексты и описания, перевод, советы по картинке. Каждый разговор — отдельный чат: слева список, «Новый чат», удаление. Чаты сохраняются между запусками.
- **Последние картинки**: меню у индикатора нейросети справа вверху. Туда сами попадают все результаты нейросетей: улучшение, вырезанный фон, правки, новые картинки. Одним кликом — открыть в редакторе, отправить в вектор или вёрстку, скопировать для Photoshop и Illustrator, сохранить. Кнопка «Очистить» удаляет всё. Хранится до 150 картинок в папке `history` рядом с моделями.
- **Печать** (Ctrl+P): на обычный принтер через окно печати Windows. Картинка или вектор — вписать в лист или задать ширину в мм.
- **Вектор**: перевод в SVG, PDF, EPS, DXF на движке VTracer с выравниванием цвета. Программа находит настоящие цвета картинки, убирает полутона и шум по краям, и одинаковые участки получают ровно один цвет. Перед трассировкой работает нейросеть: увеличивает картинку и чистит края от шума и размытия, контуры получаются ровнее («Авто» — для картинок меньше 1500 px, «Всегда» — для всех). «Только объект» — нейросеть BiRefNet находит границу объекта, фон становится прозрачным. PNG с прозрачным фоном векторизуются без фона. Можно задать свои цвета, например фирменные, и использовать только их. Большие картинки, до 4000 px, считаются в фоне, окно не зависает.
- **Вёрстка**: подгонка под формат и печать.
  - Меню на скобе: страницы разворотами, проверка кратности 4, перестановка страниц.
  - Афиша: одна работа на A4, A3, A2, A1 и свои размеры. При добавлении формата элементы переносятся с подгонкой, «Все форматы рядом» показывает их вместе.
  - Вылеты, безопасная зона, привязки к краям, центру и другим элементам. Предупреждение, если у картинки мало dpi для печати.
  - Картинки PNG, JPG и WebP, SVG, PDF из Illustrator (вставляется векторно), текст шрифтами из системы (встраиваются в PDF), плашки.
  - Экспорт: PDF для типографии с вылетами, PDF с метками реза, PDF спуском полос для печати дома, PNG 300 dpi. Проект можно сохранить и открыть позже.
  - Печать на принтере: меню брошюрой (листы сразу в порядке для сложения, двусторонняя печать), каждая страница отдельно или только текущая; A4 или A3, как в жизни (100%) или вписать в лист, метки реза.

## Первый запуск
1. Запусти `Studio-1.1.0-portable.exe`. Если Windows покажет «Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае»: у программы нет платной цифровой подписи.
2. Открой вкладку **Модели** и скачай нужные наборы (всего около 12 ГБ, один раз):
   - Улучшение качества — 45 МБ
   - Фон и лишние предметы — 0,4 ГБ
   - Рисование и правка — 5,5 ГБ
   - Проверка макета и ассистент — 5,8 ГБ (или 3 ГБ с моделью 4B)
3. Модели хранятся в `C:\StudioAI`. Папку можно сменить там же, лучше на диск D. В пути не должно быть русских букв.

## Если что-то не работает
- **Нейросеть не запускается.** Обнови драйвер видеокарты AMD (AMD Software: Adrenalin Edition): движки работают через Vulkan. Подробности в разделе «Модели» → «Журнал нейросети».
- **Загрузка обрывается.** Нажми «Скачать» ещё раз, загрузка продолжится с места обрыва. Если не помогает, переключи «Откуда качать» на «Зеркало».
- **Медленно.** На RX 5600 картинка 1024×1024 рисуется от 30 секунд до нескольких минут. Одновременно в памяти видеокарты помещается только одна нейросеть, переключение занимает несколько секунд. Кнопка «Выгрузить» вверху освобождает память.

## Сборка из исходников
```
npm install
npm start          # запуск
npm run dist       # портативный .exe в папке dist
```
