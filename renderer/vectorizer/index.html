Палитра

Слить похожие оттенки Цвета ближе допуска по оттенку станут одним — самым крупным по площади.
Квадрат — перекрасить весь цвет. HEX — выделить все области этого цвета.

Настройки трассировки

Сколько похожих оттенков считать одним цветом. Правее — меньше цветов и ровнее заливки.
Больше — точнее углы, но больше узлов
Подготовка нейросетью
Нейросеть увеличивает картинку и убирает шум и размытие по краям — контуры получаются ровнее. «Авто» — для картинок меньше 1500 px, «Всегда» — и для больших (дольше).
Новые настройки пересобирают вектор. Если нужно, верни прошлый результат кнопкой «Отменить».

Свои цвета

Свои цвета заменяют похожие найденные точно, без соседних оттенков. Удобно для фирменных цветов.
